## 2026-09-28

- **Launcher hardening** ([#48](https://github.com/bal7hazar/grimworld/pull/48)): `--with-sepolia` only for a task whose brief on `origin/main` holds the grant line and names the profile; the grant recorded, a resume without it says so; the agent count fails closed, counts detached agents by their launch record, and runs under the shared lock `~/orchestrator/agent-launch.lock`; no claude launch without a systemd user manager. Merged after three fix loops with one commit unaudited (exception recorded in [the report](docs/reports/PR-43-46-48-launcher-audit-gpt-6-sol.md)); re-audit of the merged state pending.
- **SPK-1 latency and cost on Sepolia** ([#45](https://github.com/bal7hazar/grimworld/pull/45)): SPK-2's native contracts deployed on Sepolia and measured from the owner's account (105 transactions, 72.22 test STRK). Expedition $0.874 (S1) and $0.685 (S2) at today's mainnet prices: **the $0.50 threshold does not hold**; about 1.09M L2 gas of every transaction is account and protocol, more than S1's whole fight budget. p95 to pre-confirmed 2.8 s (ADR-0001's 3 s met), p50 not decided. Research: [docs/research/SPK-1-sepolia.md](docs/research/SPK-1-sepolia.md). Audit `[GPT-6-Astra]` PASS WITH FINDINGS after one fix loop. Decision requested: [docs/decisions/2026-09-28-sepolia-verdict.md](docs/decisions/2026-09-28-sepolia-verdict.md).
- **FND-06 gas tooling** ([#42](https://github.com/bal7hazar/grimworld/pull/42)): `scripts/gas_budgets.py` generates `docs/BUDGETS.md` and a `GAS.md` per contracts package from the test run, and `--check` (in CI's contracts job, after `--self-test`) fails on a test without budget (ignored and cfg-gated included), a budget above ceil(1.05 × measured) (the most expensive run or case for fuzz and parameterized tests), a raise without a `// gas: raised, <reason>` comment, a stale file or unverifiable provenance; `--report` prints the REPORT gas table. CAIRO §2 and COMMON §7 updated. Audit `[GPT-6-Sol]` PASS WITH FINDINGS after two fix loops: [docs/reports/FND-06-audit-gpt-6-sol.md](docs/reports/FND-06-audit-gpt-6-sol.md).
- **Launcher enforces the agent budget** ([#46](https://github.com/bal7hazar/grimworld/pull/46)): a launch or resume is refused while 3 Grim World agents run (units of the three tracks and codex audits). Audit: see #48.
- **Sepolia account scoped** ([#43](https://github.com/bal7hazar/grimworld/pull/43)): the launcher empties the Sepolia account variables for every agent unless the task's brief grants the account and it is launched with `--with-sepolia` (claude only); OPERATIONS §7 and COMMON carry the owner's rules (by name only, chain id checked before sending, measure do not loop). SPK-1 brief unblocked. Audit: see #48.
- **Secrets out of agents** ([#38](https://github.com/bal7hazar/grimworld/pull/38)): every claude agent runs with the Scarb registry token emptied; the profiles deny reading `~/.claude`, printing the variable, listing the environment and `scarb publish`. Residual (an interpreter can read the same user's settings file) with the owner. Audit: [docs/reports/PR-38-secrets-audit-gpt-6-sol.md](docs/reports/PR-38-secrets-audit-gpt-6-sol.md).
