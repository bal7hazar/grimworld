# D-190: L-M2 (LIB-06) starts after LIB-04f; the 0.1.0 cut

| | |
|---|---|
| Decided by | project manager, 2026-10-02; recorded by the project manager |

## Decided

L-M2 (LIB-06) starts after LIB-04f. The `hexx` 0.1.0-rc.2 release commit is fixed before the first L-M2 merge. 0.1.0 stable is cut from that content; any later fix goes on a release branch.

## Why

A stable version must carry what the release candidate proved; L-M2 work must not enter it unreviewed by the candidate's checks.

## What would reverse it

A blocker found in rc.2 needing L-M2 content, or the owner's word on the stable version.
