# NS-2: the indexer is our own — decided 2026-09-28 (D-130)

| | |
|---|---|
| Asked by | `[Opus 5.5]` game orchestrator, from SPK-11 |
| Decided by | `[Fable 5.1]` project manager, under D-128 |
| Source | `docs/research/SPK-11-indexer.md` (`[Opus 5.5]`); audit `[GPT-6-Sol]`: PASS after two fix loops (`docs/reports/SPK-11-audit-gpt-6-sol.md`); prototype in `spikes/SPK-11/` |

## Decision

| # | |
|---|---|
| 1 | **The indexer is our own**: one TypeScript process that follows a Starknet node over JSON-RPC, decodes our events, keeps tables in which every row is versioned by block, serves queries over HTTP and subscriptions over server-sent events |
| 2 | **Its correctness rules are part of the design** (SPK-11 §4): tip checked by hash, rewind in one transaction on a reorg, no block served before reconciliation, a halt on a missing event, a freshness rule in the client |
| 3 | **The nine events and the two extra views** (`open_lot_count`, `trade_count`) found by SPK-11 are inputs of ENG-01, which freezes them |
| 4 | It is built in **a track of its own, IDX, after ENG-01**, in this repository |
| 5 | SQLite for the MVP and the test networks. The storage engine is chosen again before mainnet (HRD), with Ekubo's indexer (JSON-RPC into Postgres) as the reference design |

## Why

| | |
|---|---|
| The job is small | 7 reads in the MVP, 6 events, 3 more events for the rankings later. Everything the player needs to play is read by view calls and the client's simulation (ADR-0007) |
| Nothing generic fits cheaply | Torii: Dojo worlds only. SubQuery: no reorg handling on Starknet. Apibara, Substreams: several services. Checkpoint, the closest: Postgres, no subscriptions, beta |
| Reorgs are proven | On the local node's aborted blocks, answer by answer: live, at restart, in the middle of a read |
| Operations | One process, one file, rebuilt by deleting the file |

## What it costs

| | |
|---|---|
| Gas | An event is about 2 % of an action's gas |
| Disk | 137 bytes per event |
| RPC | About $43 a month at a poll of 1 s: **a projection, and a spending**. Test networks run on a free endpoint; a paid endpoint is the owner's decision (D-128), asked before mainnet |

## What would reverse it

A scope that grows beyond what one process serves (full history search, analytics), or a
generic indexer that gains reorg handling and subscriptions on Starknet. The events are the
interface: changing the indexer does not change the contracts.
