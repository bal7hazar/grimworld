# D-192: CLI-02: client/sim lent to track CV

| | |
|---|---|
| Decided by | project manager, 2026-10-02; recorded by the project manager |

## Decided

`client/sim/**` is lent to track CV. A game PR that moves a vector updates the TS mirror when it is a few lines; a new rule gets a paired CV PR. The full-tick threshold is 10 queued actions within 16.7 ms (Node and a browser worker). The Capacitor shell is CV-03, iOS only (D-152).

## Why

The client's simulation mirrors the vectors (D-140); one owner of the mirror avoids a second queue of small PRs.

## What would reverse it

Mirror drift costing more than it saves, or a measurement showing 16.7 ms unreachable (then the threshold is re-decided).
