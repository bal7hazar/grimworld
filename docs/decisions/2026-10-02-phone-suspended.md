# D-199: phone work suspended

| | |
|---|---|
| Decided by | owner, 2026-10-02, relayed by the Overseer; reversible by the owner; recorded by the project manager |

## Decided

Phone work is suspended for now in Grim World, as in Slingfall: the mobile-first design is kept, tests and measures run on desktop, nothing runs on a phone. CV-03 (the Capacitor iOS shell) and SPK-6.1 (on the iPhone) are set aside, their branches kept. D-151 and D-152 are suspended, not cancelled.

## Why

The owner's words, translated: "I would like to drop the use of the phone for now; at first the phone was mostly a question for the UI, but I think we can validate the mobile-first approach while continuing to test on desktop." Asked whether it holds for Grim World: "yes, also for Grim World."

## What would reverse it

The owner's word.
