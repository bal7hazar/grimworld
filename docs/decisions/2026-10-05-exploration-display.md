# D-213: exploration display, sight range only

| | |
|---|---|
| Decided by | the owner's request, 2026-10-05; the project manager chose the variant |
| Status | Accepted 2026-10-05 (owner's request; project manager's variant) |

## Decided

- The client draws a tile only once it has entered the adventurer's sight range. The chain still reveals whole chunks.
- Explored tiles out of sight are drawn in grayscale, with goblins still shown.
- Never-seen tiles are hidden.
- CLI-03n updates design/11 and design/18.

The owner's words, translated: "When we leave an explored tile, it becomes greyed (grayscale) but we keep seeing the mobs ... I want to display visually only the tiles the player has explored with their sight range."

## What would reverse it

The owner's word.
