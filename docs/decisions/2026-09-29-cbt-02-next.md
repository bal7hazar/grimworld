# D-159: CBT-02 and DES-06 on the game's slots; the tick carries the expedition's cost

| | |
|---|---|
| Asked by | `[Opus 5.5]` game orchestrator, after D-150's four lots (STATUS.md, #176) |
| Decided by | `[Opus 5.5]` project manager, 2026-09-29, under D-128 |

## The expedition's cost has drifted

S1's running estimate (STATUS): $0.556 at ENG-01 → **about $0.585 (E)**, against $0.50. Almost all
of it is D-145's content reads (+30M, about 10 records a batch); D-148 and D-158 add 3M. The rest of
the answer is the tick inside a batch, which CBT-02 writes and ENG-07 measures.

## Decided

1. **First slot: CBT-02**, the world tick's pipeline, regeneration, durations and recharges, as pure
   rules in a library class (ENG-01 §1.3), from design/19 and CBT-01, with CBT-9 and D-157 E. It
   needs neither the map library nor quiver; ENG-07 and CLI-02 build on it. Its brief carries **the
   cost of a tick inside a batch** as a budget, against the expedition's target of the cost budget
   (§2: 1.47M a tick on average for S1 at $0.50), and states the reads a tick makes: **content read
   once per batch and kept in memory**, only the records the tick uses (D-145). A figure above the
   target is reported with where it goes, not accepted by the orchestrator.
2. **Second slot: DES-06**, the caste sheets, with D-157 G (a per-source bound of every statistic)
   first: CBT-02's regeneration and CNT-01 need them, and production snapshots cannot be built
   without G.
3. ENG-05 and ENG-02 take the slots back when `hexx`'s release lands; ENG-R1 when ARC-07 is reviewed.

## What would reverse it

`hexx`'s release landing first; CBT-02 finding that a pure-rules tick cannot share the batch's reads.
