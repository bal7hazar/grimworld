### What the diff introduced, reviewed

- **`HANDOFF` guard.** `bootstrap` sets `GRIMWORLD_ART_VENV=1` before `execv` and refuses to loop when the variable is set but the process is not inside the venv. This closes a re-exec loop (a venv whose interpreter resolves outside itself). `test_handoff_happens_once` covers it. Correct.
- **Running-venv validation.** Started directly from `tools/art/.venv`, the script checks the venv it runs in (`pyvenv.cfg` readable, version at least 3.12 and equal to the cfg's, pins match) and refuses, naming the running venv, instead of rebuilding under itself. Tests: `test_direct_launch_from_a_good_venv`, `test_direct_launch_from_an_unpinned_venv_refuses`, `test_venv_without_pyvenv_cfg_rebuilds`. Refusing rather than rebuilding the running venv is the right call. `pins()` reads across `\` continuations and `--hash` lines, so the hashed file parses.
- **`height_spec` removed, `height_problem` added.** One place says what a line of `[height]` may be; no reference to `height_spec` remains under `tools/art`.
- **`manifest.toml`.** `basic = ["runt","skirmisher","slinger"]`, `exempt = ["skirmisher"]`, `tallest = "hobgoblin"`. The exemption states its number and reason, and the code enforces native-only, so it cannot silently cover a resampled sprite.
- **Housekeeping.** No committed image files and no `tools/art/out` contents; the working tree is clean (checked with `git ls-files` and `git status`).
