# except force-push, and opening the pull request. Never merging it.
# Format: see research.txt.
# The deny rules below stop these actions when they are typed as commands. They do not stop an
# interpreter, a test or a project script, which can do anything the user can: that is the
# price of running code. What holds whatever the agent runs is elsewhere: no secret in the
# agent's environment, the CI checks (assets), and the protection of `main` on GitHub.
