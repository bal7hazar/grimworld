# SPK-7 — chunked map spike

A Scarb package on the repository's toolchain (root `.tool-versions`: Scarb 2.19.4, snforge 0.61.0,
starknet-devnet 0.10.0), with `origami_hexmap` 1.8.0 by published version. Throwaway. Results:
[docs/research/SPK-7-chunked-maps.md](../../docs/research/SPK-7-chunked-maps.md).

| File | What |
|---|---|
| `src/window.cairo` | `assemble_window` (N-3), `scatter_window` (its inverse, for variant B′), `window_origin` |
| `src/chunk.cairo` | `generate_chunk` (N-1, N-2): base, lines to a spine, automaton with margins, component; the parity flag |
| `src/flood.cairo` | `shared_flood` (N-8), `step` (rule (a)) |
| `src/sight.cairo` | `line_of_sight`, `between_mask` (N-5) |
| `src/tick.cairo` | `world_tick` (goblins on the window), `move_goblin` / `apply_moves` (item 4) |
| `src/contract.cairo` | `Instances`: `reveal`, `act` (A), `act_stored` (B), `act_deferred` (B′), `act_standin` (S) |
| `src/vectors.cairo` | Generated by `vectors.py` (then `scarb fmt`) |
| `src/tables.cairo`, `src/boards.cairo` | Generated by `gen_tables.py` and `boards.py` (then `scarb fmt`) |
| `model.py` | The rules in plain Python, tile by tile: the source of the tables and boards |
| `vectors.py` | Shared vectors of the flood: checked on the model, written to `src/vectors.cairo` for `test_flood_shared_vectors` |
| `tune.py` | Biome parameters against design/18's walkable shares |
| `devnet.py`, `summarize.py` | The transactions on the local node, and their table |
| `snforge-test-output.txt`, `devnet-output-{1,2,3}.txt`, `devnet-summary.md` | Raw outputs |
| `BUDGETS.md`, `GAS.md` | Written by `scripts/gas_budgets.py` (below) |

From the repository root:

```
python3 spikes/SPK-7/gen_tables.py && python3 spikes/SPK-7/boards.py && python3 spikes/SPK-7/vectors.py   # then scarb fmt
scripts/lock.sh scarb --manifest-path spikes/SPK-7/Scarb.toml build
cd spikes/SPK-7 && snforge test > snforge-test-output.txt && cd -          # 106 tests, budgets
scripts/with-node.sh python3 spikes/SPK-7/devnet.py > spikes/SPK-7/devnet-output-1.txt   # x3
python3 spikes/SPK-7/summarize.py spikes/SPK-7/devnet-output-*.txt > spikes/SPK-7/devnet-summary.md
```

Budgets are set with `python3 ../SPK-2/set_budgets.py snforge-test-output.txt` from this folder
(`ceil(1.05 × measured)`). `BUDGETS.md` and `GAS.md` come from `scripts/gas_budgets.py`, which
reads a workspace: a throwaway manifest outside git (`.with-node/gasws/Scarb.toml` with
`[workspace] members = ["../../spikes/SPK-7"]`), fed the run with the test crate renamed
(`spk7_tests::` → `spk7_integrationtest::`, the prefix the tool strips):

```
python3 scripts/gas_budgets.py --workspace .with-node/gasws --budgets spikes/SPK-7/BUDGETS.md --from-output .with-node/spk7-output.txt
```

The oracle tests run up to 2.4 billion L2 gas: `max_n_steps` is raised in `Scarb.toml`.
