# SPK-14 — hexagonal chunks of 251 tiles (D-165)

A Scarb package on the repository's toolchain (Scarb 2.19.4, snforge 0.61.0), with the map library
`hexx` read **by git at commit `93639f2c17e3`** (`Scarb.toml`), never copied. Throwaway. Results:
[docs/research/SPK-14-hexagonal-chunks.md](../../docs/research/SPK-14-hexagonal-chunks.md).

| File | What |
|---|---|
| `src/hexchunk.cairo` | The 9-9-11 chunk: `index` (tile → bit), `tile` (bit → tile), `locate` (tile → chunk, lattice rounding) |
| `src/window.cairo` | `HexWindowTrait::window`: the 15 × 16 window from up to 6 hexagonal chunks, a walk of row runs; `HexWindowTableTrait::window`: the same with every piece precomputed (the floor); `origin` |
| `src/hexgen.cairo` | `HexChunkGenTrait::generate`: a hexagonal chunk's generation with margins, on two half-boards of stride 19, packed at the end |
| `src/rect.cairo` | SPK-7's `generate_chunk` on `hexx`, the rectangle on the same basis |
| `src/automaton.cairo`, `src/types.cairo` | SPK-7's rule, biomes and sides, shared |
| `src/tables.cairo`, `src/pieces.cairo` | Generated by `gen_tables.py` (`pieces.cairo` is left out of `scarb fmt`: `.cairofmtignore`) |
| Unit tests | In their modules (D-167): `hexchunk.cairo` (bijection, `locate`), `window.cairo` (every origin class against a direct construction), `hexgen.cairo` (the automaton and the component against plain versions, whole chunks, the rectangle); helpers in `src/testing.cairo` |
| `tests/` | Gas benchmarks only: `bench_window.cairo`, `bench_generation.cairo`, and the unit costs `test_micro.cairo` |
| `summary.md` | `summarize.py`'s table of the two runs |
| `geometry.py` | The shape in plain Python: bijection, tiling, window overlaps and runs, sight, linear layouts, the Cairo walk against a direct construction on every origin class; output in `geometry-output.txt` |
| `generation.py` | The constants of both generators, and the checks of the six sides' copy maps |
| `summarize.py` | The benchmarks (twice − once) and unit costs of snforge runs |
| `set_budgets.py` | Budgets `ceil(1.05 × measured)`, measured being the higher of the runs given |
| `test.sh` | Tables, format, `snforge test` into a file |
| `snforge-test-output-{1,2}.txt` | The two runs, each from a clean build (D-154) |
| `BUDGETS.md`, `GAS.md` | Written by `scripts/gas_budgets.py` |

From the repository root:

```
python3 spikes/SPK-14/geometry.py > spikes/SPK-14/geometry-output.txt
scarb --manifest-path spikes/SPK-14/Scarb.toml clean && spikes/SPK-14/test.sh snforge-test-output-1.txt   # 66 tests
scarb --manifest-path spikes/SPK-14/Scarb.toml clean && spikes/SPK-14/test.sh snforge-test-output-2.txt
python3 spikes/SPK-14/summarize.py spikes/SPK-14/snforge-test-output-1.txt spikes/SPK-14/snforge-test-output-2.txt
python3 spikes/SPK-14/set_budgets.py spikes/SPK-14/snforge-test-output-1.txt spikes/SPK-14/snforge-test-output-2.txt
```
